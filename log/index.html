Umbra, and a quieter room

The newest thing on the front page is Umbra: a multi-session desktop browser where every tab is its own isolated browser. Each tab gets its own cookies, storage and cache, its own proxy and exit IP, and its own fingerprint — screen, graphics, fonts and clock set together so they agree with each other and with the network they appear on. It's for people who genuinely need many accounts, QA across regions, or want to see a page from somewhere they aren't.

Under the hood it's an Electron, React and TypeScript desktop app, with a small Go network engine doing the wire-level work and a Next.js account platform behind it. It's in beta, and it's where most of my evenings go. Its page on this site walks through the core idea: one machine, five sealed sessions, nothing shared between them.

The site changed with it. It is quieter now: off-white and grey, one typeface, and the manners of an older kind of computer. Windows zoom open from their centres. Text types itself in behind a block caret. Paragraphs arrive through a dithered dissolve. The sphere on the index is shaded per pixel, reduced to one bit with an ordered dither, and lit from wherever your cursor is. Each project now has a page of its own, laid out around what that project actually does. Still no frameworks, still no build step.

I06.07.2026

Building this place

This site went from an empty folder to a working page in a handful of build sessions: no frameworks, no build step — hand-written HTML, one stylesheet, and a single script doing everything you can see. Everything drawn on the page was hand-rolled canvas and plain JavaScript then, and still is.

Some things I learned shipping it. The .gg registry publishes its zone in batches, so marcus.gg spent its first afternoon registered but invisible to the entire internet — nothing was wrong, the Channel Islands just publish on their own schedule. GitHub Pages will quietly refuse to issue an HTTPS certificate if you attach a domain before its DNS exists; removing and re-adding the domain wakes it up. And Jekyll was processing this site on every deploy for no reason at all until a .nojekyll file put a stop to it.

The first version opened on a duel between my two Old School RuneScape characters, with a quest log where a skills grid would usually go. Both have retired to the git history, where the duel is still perfectly playable.
