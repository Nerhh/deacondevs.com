Umbra

A desktop browser where every tab is its own sealed browser — its own cookies, its own exit IP, its own consistent device. Many accounts side by side on one machine, nothing linking them.

1 window · 1 session01 / 05

01 / 05

One machine.

It starts as any browser does: one window on one machine, and one session holding its cookies, storage and cache.

02 / 05

Sealed sessions.

Every tab becomes its own sealed browser: a separate session partition per profile, or a throwaway one that leaves nothing on disk. Nothing set in one can reach another.

Click or tap a partition to drop a cookie in. It stays on its own side of the wall.

03 / 05

Its own place.

Each profile has its own proxy and exit IP, tested in one click, spread evenly across the pool and rotated on your schedule. Time zone and locale follow the exit region.

04 / 05

Every signal agrees.

Each profile presents one consistent, realistic browser environment, set as a whole from real device templates. Its screen, clock, locale, network location and TLS/HTTP-2 signature all agree.

05 / 05

Verify, don't trust.

A self-consistency scorecard gives each profile one verdict: isolated, warnings or exposed. A separation report names any link left between profiles, with a one-click fix.

Who it is for

People who legitimately run many identities: agencies keeping client logins apart, QA across regions and locales, ad and landing-page verification, affiliate campaign testing, and market and privacy research. It is built for isolation and privacy, not concealment.

The rule

Umbra never auto-buys. Managed automation stops at filling forms and navigating; the committing action is always a person's, and the tests hold it to that.

Facts

Platform
Desktop app in Electron, React and TypeScript
Network engine
Go, loopback only; re-originates each connection so its TLS and HTTP/2 match the profile
Accounts and sync
Next.js account platform; data sealed with AES-256-GCM before upload, key derived from a passphrase with scrypt
Team
Live tab snapshots up, decisions back; owner, manager, operator and viewer roles enforced on the server
Tests
About 790 unit test files; the Go engine is 37 source files, 26 of them tests
